# Simple Static Site

A responsive personal portfolio and project showcase built with semantic HTML5 and modern CSS3, deployed via GitHub Pages.

## Live Demo
View the live site at: `https://github.io`

## Features
- **Semantic HTML5**: Uses `<nav>`, `<header>`, `<main>`, `<section>`, `<article>`, and `<footer>` with ARIA accessibility labels.
- **Modern CSS3**: Built with CSS custom properties (`:root`), Flexbox, CSS Grid, smooth scrolling, and mobile `@media` breakpoints.
- **Clean Repository Structure**: Organized with `index.html`, `style.css`, and `README.md`.

## Project Structure
- `index.html` — Main HTML5 page structure and navigation
- `style.css` — Custom CSS variables, responsive grid/flexbox layouts, and hover transitions
- `README.md` — Project documentation and setup instructions

## How to Run Locally
1. Clone the repository: `git clone https://github.com`
2. Open `index.html` in any web browser.
