# Simple Static Site

A responsive static website built with semantic HTML5 and CSS3, hosted in a GitHub repository.

## Project Structure
- `index.html` — Semantic HTML5 document structure
- `style.css` — Responsive styling, flexbox layout, and card components
- `README.md` — Project overview and setup instructions

## How to View Locally
1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
